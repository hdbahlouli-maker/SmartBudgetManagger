
# SmartBudget Manager

## Overview
**SmartBudget Manager** (`SmartBudget_Manager.xlsx`) is an Excel workbook designed to help users manage their finances easily[cite: 15]. It allows users to:
- Record monthly income and expenses[cite: 15].
- Categorize expenses (Food, Transport, Rent, Health, Education, etc.)[cite: 15].
- Calculate the monthly balance automatically[cite: 15].
- Display charts of expenses by category[cite: 15].
- Receive a warning when the budget limit is exceeded[cite: 15].

## Requirements
- Microsoft Excel (2016, 2019, 2021, Microsoft 365) or an equivalent compatible spreadsheet software[cite: 15].

## Getting Started
1. Open `SmartBudget_Manager.xlsx`[cite: 15, 16].
2. Go to the **Transactions** worksheet to enter your income and expenses[cite: 15, 16].
3. Select a category from the predefined list in the **Categories** worksheet[cite: 15, 16].
4. Check the **Dashboard** worksheet to view your monthly balance, totals, and expense charts[cite: 15, 16].
